## Descrição do projeto
A Nuances Kids é uma loja fictícia de roupas infantojuvenis. O projeto apresenta cinco produtos e permite simular uma compra, informando as quantidades desejadas.

## Produtos disponíveis
- Vestido infantil — R$ 89,90
- Camiseta juvenil — R$ 33,50
- Bermuda sarja — R$ 45,00
- Vestido de festa infantil — R$ 129,90
- Conjunto Juvenil Brasil — R$ 62,50

## Tecnologias utilizadas
HTML, CSS e JavaScript.

## Como executar
1. Abra a pasta Nuances Kids.
2. Clique duas vezes no arquivo `index.html`.
3. A loja será aberta no navegador.
4. Clique em "Simular compra" e informe as quantidades desejadas.

## Funcionamento e testes
O programa calcula o valor da compra de acordo com os produtos selecionados. Compras a partir de R$ 200,00 recebem 10% de desconto.

Foi realizado um teste selecionando um vestido infantil e duas camisetas juvenis. O sistema apresentou corretamente o total de R$ 156,90.
